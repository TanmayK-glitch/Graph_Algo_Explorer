# Instructions for AI Coding Agents

**Before any code or documentation change in this repository, read `./skills.md` in full.** It is the project's shared skill library and API/naming contract.

For each task:
1. Inspect relevant existing source code, tests, and the root README.
2. Follow `skills.md` public names, graph formats, result types, benchmark schemas, and compatibility rules.
3. Flag conflicts with actual code instead of silently rewriting teammates' modules or inventing APIs.
4. Make the smallest safe change and run the relevant tests.
5. Summarize changed files, test commands/results, and any unverified assumptions.

If `skills.md` is unavailable, ask for it before making interface-changing edits.
